# 홈택스 부가가치세 자료 수집 — 단일 파일 실행판

`hometax_vat_downloader.py`와 거래처 입력 엑셀만 같은 폴더에 두고 실행합니다. 실행 파일 안에 입력 검증, 과세기간 계산, 1~7번 작업계획, 브라우저 조작, 다운로드 검증, 기록 기능을 모두 포함했습니다. `vat_core.py`, `prepare_input.py`, JSON 설정, BAT, requirements 파일은 일반 실행에 필요 없습니다.

2026년 귀속과 계산서 매출·매입 모두라는 사용자 답변을 적용합니다. 기본 모드는 `auto`입니다. 수동 로그인 후 메뉴 이동과 거래처별 조건 설정·조회·저장을 진행하며 **Enter 확인을 요구하지 않습니다.** 이전 버전의 마지막 `완료 후 Enter…`는 오류가 아니라 수동 확인을 기다리던 코드였습니다.

실제 홈택스 로그인 뒤 화면과 Windows CLIP report 인쇄는 이 클라우드에서 검증하지 못했습니다. 첨부 화면과 기존 성공 코드의 메뉴 이동 방식에 맞춰 보완했고, 실제 Chromium의 로컬 시험으로 조작 로직을 검증합니다. 현장 화면이 달라 선택값을 대조하지 못하면 조회를 실행하지 않고 오류를 남깁니다.

## Windows에서 실행

Python 3.11 이상과 Google Chrome이 설치되어 있어야 합니다. 기존 실행이 CMD에서 기다리고 있다면 **Ctrl+C**로 중단하세요. 새 버전으로 처음 바꿀 때는 이전 코드가 연 **홈택스 전용 Chrome 창**을 닫으세요. 일반 Chrome은 닫을 필요가 없습니다.

1. 새 `hometax_vat_downloader.py`를 내려받아 기존 파일을 교체합니다. 다운로드 후 파일명이 `.py.txt`가 되지 않았는지 탐색기에서 확장자를 표시해 확인하세요.
2. 기존 입력 엑셀을 같은 폴더에 둡니다. 원래 `INPUT-부가세.xlsx` 또는 수정한 `INPUT-부가세_확장.xlsx`를 그대로 사용할 수 있습니다. 엑셀 수정 내용을 저장하세요.
3. CMD에서 해당 폴더로 이동한 뒤 실행합니다.

```bat
cd /d "C:\Users\jangs\OneDrive\2. 파이선\코덱스_국세청auto"
python hometax_vat_downloader.py
```

첫 실행에 필요한 패키지가 없으면 해당 Python에 `openpyxl`, `playwright`, `pypdf`를 설치합니다. 설치에는 인터넷이 필요합니다. Chrome에 연결하므로 ChromeDriver 및 Playwright 전용 브라우저 설치 명령은 필요 없습니다. 이미 설치된 패키지는 자동으로 변경하지 않습니다. 검증된 버전은 `requirements.txt`에 있습니다.

전용 Chrome에서 **세무대리인**으로 로그인하세요. 로그인 완료를 감지하면 다음 순서로 진행합니다.

> 세무대리·납세관리 → 세무대리 공통조회 → 부가가치세 신고도움 서비스 → 입력 거래처의 사업자번호·연도·기수·예정/확정 설정 → 조회 → 인쇄·저장

나머지 항목도 해당 조회 메뉴로 이동합니다. 인증서·비밀번호·인증번호 및 수임 동의는 사용자가 처리합니다. 인증정보를 엑셀에 넣지 마세요.

**파일 선택:** 같은 폴더에 확장 엑셀과 원래 엑셀이 모두 있으면 `INPUT-부가세_확장.xlsx`가 우선입니다. 그 다음 `INPUT-부가세.xlsx`, `INPUT_VAT_2026.xlsx` 순서입니다. 알려진 이름이 없고 실제 엑셀이 하나뿐이면 그 파일을 사용합니다. 공개 빈양식은 자동 선택하지 않습니다. 다른 파일을 쓰려면 지정하세요.

```bat
python hometax_vat_downloader.py --input "내거래처.xlsx"
```

## 처음 확인할 명령

브라우저를 열지 않고 엑셀·업무계획만 점검:

```bat
python hometax_vat_downloader.py --validate-only
```

신고도움서비스 1번만 자동 실행:

```bat
python hometax_vat_downloader.py --services 1
```

전체 1~7번 실행은 옵션 없는 기본 명령입니다. 작업 중에는 마우스로 조회 화면을 변경하거나 메인 탭을 닫지 마세요. CMD에 현재 메뉴·조건설정·조회대기·저장단계를 표시합니다. 로그인 대기는 20초마다 상태를 알립니다. 기본 조회 대기는 60초, 원본 파일생성 대기는 360초입니다.

## 입력과 작업 분기

필수 열은 `사업자명`, `사업자등록번호`, `과세기간`입니다. 원래 `NO`, `대표이사`는 유지해도 됩니다. 사업자번호는 텍스트로 보관하며 하이픈을 허용합니다. 과세기간은 `1기예정/1기확정/2기예정/2기확정` 중 하나입니다.

원래 엑셀에 과세연도가 없으면 **2026년**을 적용합니다. 엑셀의 `과세연도` 값이 우선합니다. 2027년 등 다른 연도는 엑셀에 적거나 `--year 2027`로 보완하세요. 조회항목·계산서종류·매출매입구분·저장형식 열이 없어도 기본값으로 실행합니다. 선택 열은 [입력항목_요약.md](입력항목_요약.md)에 있습니다.

| 번호 | 대상 | 기본 처리 |
|---|---|---|
| 1 | 부가가치세 신고도움서비스 | 사업자·연도·기수·예정/확정 → 전체보고서 PDF |
| 2 | 전자(세금)계산서 합계표 | 수임사업자 전환 → 전자세금계산서/전자계산서 × 매출/매입 → 기간 조회·PDF |
| 3 | 신용카드/판매대행 매출 | 결제연도·시작/종료분기 → 인쇄 PDF |
| 4 | 현금영수증 매출총액 | 연도·월별 조회 → 월별 PDF |
| 5 | 매입자납부 특례 | 거래내역·품목/매입매출 전체·적용분기 → 원본 + 조회화면 증빙 PDF |
| 6 | 수출실적명세서 | 조회단위·기간 → 파일생성 완료 → 원본 + 보고서 PDF |
| 7 | 내국신용장·구매확인서 | 두 서류 각각 연도·기수·신고구분 → 파일생성 → 원본 + 보고서 PDF |

2026년 2기예정 거래처 한 곳은 기본 13개 세부 작업입니다. 2번은 4개, 4번은 7~9월 3개, 7번은 두 서류로 분리합니다. 조회계획 수와 실제 생성 파일 수는 다릅니다.

| 과세기간 | 기본 범위 |
|---|---|
| 1기예정 | 1~3월 |
| 1기확정 | 1~6월 |
| 2기예정 | 7~9월 |
| 2기확정 | 7~12월 |

확정신고에 `조회범위=분기`를 명시하면 1기는 4~6월, 2기는 10~12월입니다. 첨부 7번 화면에는 확정신고 분기 단독 선택이 없어 그 조합은 실행 전에 거절합니다. 7번을 제외하거나 반기를 사용하세요.

## 자동 선택·오류 처리

메뉴의 공백·가운데점 차이를 허용하고 hover 후 클릭하며 하위 메뉴가 나타날 때까지 기다립니다. 기수 등 WebSquare 선택상자는 펼친 목록에서 값을 골라 표시값을 다시 읽습니다. 일반 HTML select도 지원합니다. 조회 직전에 사업자·기간·라디오 선택값을 다시 대조하여 다른 입력이 조건을 초기화한 경우를 검출합니다.

자동 모드에서 필수 입력을 찾지 못하거나 같은 이름의 요소가 여러 개이면 추측하지 않습니다. 첫 오류에서 멈추고 현재 단계, 원인, `오류진단.json` 위치를 출력합니다. 파일에는 입력값·쿠키·비밀번호·스크린샷을 수집하지 않으며 컨트롤 구조를 남깁니다. 제목/ID 등에는 사이트가 넣은 정보가 있을 수 있으므로 공유 전에 확인하세요. 필요한 경우 `--continue-on-error`로 실패 기록 후 다음 작업을 계속할 수 있습니다.

```bat
python hometax_vat_downloader.py --services 1 --timeout 120
python hometax_vat_downloader.py --continue-on-error
```

수동 보완이 필요한 작업에서만 `--mode assisted`를 명시하면 이전처럼 Enter 확인을 사용합니다. 기본 자동 모드의 오류에서는 입력을 기다리지 않습니다.

## 인쇄, 내용 확인, 재시작

전용 Chrome에 `Save as PDF`와 kiosk printing을 설정하여 보고서의 전체페이지 인쇄를 저장합니다. 새 버전이 시작한 Chrome은 이후 실행에서도 설정과 동일 브라우저인지 확인한 뒤 다시 연결할 수 있습니다. 이전 버전/다른 프로그램이 연 디버그 Chrome은 인쇄 설정이 불명확하므로 닫고 새 버전으로 다시 시작해야 합니다.

새 PDF만 감지하고 PDF 구조·페이지, XLSX 열기, HTML 로그인 응답 여부, SHA-256을 검사합니다. **파일 검증과 보고서의 거래처·금액 검증은 별개입니다.** 기본 자동 모드는 조건과 조회 응답을 확인하고 수집합니다. 결과 영역의 사업자·기간 증거가 없으면 `confirmed=false`, 내용 확인 필요로 기록합니다. 입력값만 보고 보고서 내용까지 검증되었다고 처리하지 않습니다. 실제 신고 사용 전 첫 산출물의 사업자·기간·전체페이지를 대조하세요.

1~4번의 엑셀 원본은 현재 수집하지 않습니다. `저장형식=모두`여도 해당 항목은 PDF입니다. 5번 및 무자료 화면은 `조회화면증빙.pdf`이며 공식 전체보고서/그리드 전체 거래를 대체하지 않습니다. 원본과 PDF 일부가 저장된 뒤 후속 출력이 실패하면 이미 저장한 파일은 보존하고 작업 전체는 실패로 남깁니다.

결과는 코드 폴더 아래 `다운로드/<작업해시>/<실행시각>`에 저장합니다. `조회조건.json`, `실행기록.jsonl`에는 로컬 대조에 필요한 정보가 있습니다. 이전 파일은 삭제하거나 덮어쓰지 않습니다.

```bat
python hometax_vat_downloader.py --resume
```

`--resume`은 저장 완료, 결과 대상 확인, 실제 파일 해시가 모두 유효한 작업만 생략합니다. 자동 수집 후 내용 확인 필요로 남은 작업은 재실행됩니다. 결과 대상 확인까지 자동화하려면 실제 화면에서 확인한 `result_ready/result_identity` 선택자를 선택적으로 지정할 수 있습니다. 일반 자동 실행에는 JSON 파일이 필수는 아닙니다.

## 선택자 확장과 전체 코드 구성

홈택스 화면이 달라지는 경우 `--inspect`로 로그인 후 원하는 화면의 제어요소 구조를 저장하거나 오류진단을 활용합니다. `selectors.example.json`의 services 항목에 실제 확인한 CSS를 설정한 뒤 `--selectors selectors.json`으로 실행합니다. 임의의 ID를 만들어 쓰지 않습니다.

사용 가능한 키: `menu`, `field:필드명`, `search`, `result_ready`, `result_identity`, `no_data`, `report`, `report_ready`, `report_identity`, `print`, `generate`, `download`. CSS 범위를 `frame_url_contains`, 실제 확인한 순서를 `index`로 한정할 수 있습니다. `no_data`는 무자료 상황에서만 보이는 요소여야 합니다. `strict` 모드는 결과/보고서 대상 증거 선택자를 요구합니다. 캔버스 보고서는 DOM에 사업자·기간 텍스트가 없어 자동 내용 확인이 제한됩니다.

| 코드 구간 | 역할 |
|---|---|
| `ensure_dependencies` | 직접 실행 시 누락된 패키지만 pip 설치 |
| `Period`, `Client`, `Job`, `load_clients`, `build_jobs` | 입력 검증, 신고기간 계산, 거래처별 1~7 작업 생성 |
| `validate_artifact`, `Journal` | 다운로드 구조/해시 검사, 실행기록 및 검증된 재사용 |
| `launch_chrome`, `chrome_binary` | 별도 Chrome 프로필·PDF 기본값·로컬 디버그 연결 |
| `Collector.navigate`, `field`, `select_custom` | 메뉴 이동, 입력란 탐색, WebSquare 선택값 대조 |
| `configure_query`, `verify_filters`, `wait_query` | 조건 재검사, 조회, 비동기 결과 대기 |
| `download`, `generate_download`, `report_pdf` | 원본 다운로드, 생성 완료 대기, 전체보고서 PDF |
| `save_diagnostics`, `main` | 구조 진단, 거래처 작업 루프, 오류 종료와 진행 표시 |

## 개발 환경 검증

```bash
cd /workspace/hometax_auto
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python hometax_vat_downloader.py --input INPUT-부가세_빈양식.xlsx --validate-only
.venv/bin/python -m pytest -q
```

브라우저 시험은 `/usr/bin/chromium`에서 요청을 로컬 HTML로 대체합니다. 실제 로그인/조회/다운로드 성공 시험이 아닙니다. 검증 결과와 후속 작업은 [검증결과.md](검증결과.md), [이어서_작업.md](이어서_작업.md)에 있습니다. 공개 저장소에는 실제 거래처 엑셀, 인증 세션, 다운로드 결과를 넣지 않습니다.
